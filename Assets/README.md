# Assets

This directory contains assets for the Ampeg SVT bass amp plugin.

## Cabinet Impulse Responses

Place bass cabinet impulse response (.wav) files in this directory.
The plugin will automatically load them for cabinet simulation.

Recommended IR characteristics:
- Sample rate: 44.1 kHz or 48 kHz
- Length: 500-2000 samples
- Format: Mono or stereo WAV
- Bass cabinet recordings (Ampeg 8x10 preferred)

## Graphics

Custom knob textures and background images can be placed here.
