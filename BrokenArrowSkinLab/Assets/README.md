# Assets Directory

This directory contains the application assets required for the WinUI application.

## Required Assets

The following PNG files are required for packaging the application:

1. **StoreLogo.png** (50x50 pixels) - Store logo
2. **Square44x44Logo.png** (44x44 pixels) - Small tile logo
3. **Square150x150Logo.png** (150x150 pixels) - Medium tile logo
4. **Wide310x150Logo.png** (310x150 pixels) - Wide tile logo
5. **SplashScreen.png** (620x300 pixels) - Application splash screen

## How to Add Assets

1. Create or obtain PNG files with the dimensions specified above
2. Place them in this directory
3. Ensure the file names match exactly as listed above

For development purposes, you can create simple placeholder images using any image editor or online tools.

- `Templates/` - Contains default project templates
