================================================================================
MODELING DETAILS
================================================================================

Tube Preamp:
  - 3 cascaded gain stages
  - Asymmetric tanh clipping
  - Progressive frequency roll-off (8/6/5 kHz)
  - Bias control for harmonic character
  - Based on 12AX7/ECC83 behavior

Tone Stack:
  - Bass: Low shelf at 100 Hz (±12 dB)
  - Mid: Parametric peak at 220/450/800/1.6k/3k Hz (±12 dB)
  - Treble: High shelf at 3 kHz (±12 dB)
  - Bright: +6 dB at 5 kHz
  - Ultra-Lo: +8 dB at 40 Hz
  - Ultra-Hi: +6 dB at 8 kHz

Power Amp:
  - Power supply sag (1ms attack, 50ms release)
  - Asymmetric saturation
  - Output transformer filter (7 kHz)
  - Based on 6550/KT88 push-pull topology

Cabinet Simulation:
  - Resonances at 80 Hz and 200 Hz
  - Speaker roll-off at 4.5 kHz
  - Sub-bass filter at 50 Hz
  - Emulates Ampeg 8x10 cabinet
  - Supports custom IR loading

================================================================================
USAGE INSTRUCTIONS
================================================================================

Quick Build:
  1. git clone --recursive https://github.com/hueyf333/Broken-Arrow-Software.git
  2. cd Broken-Arrow-Software
  3. ./validate_build.sh
  
  OR:
  
  1. mkdir build && cd build
  2. cmake .. -DCMAKE_BUILD_TYPE=Release
  3. cmake --build .

Install VST3:
  Linux:   cp -r build/AmpegSVT_artefacts/VST3/Ampeg*.vst3 ~/.vst3/
  Windows: Copy to C:\Program Files\Common Files\VST3\
  macOS:   Copy to ~/Library/Audio/Plug-Ins/VST3/
